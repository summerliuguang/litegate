# 协议与运维边界

此表描述当前实现和本轮本地回归，不代表已对每一家供应商实测。

| 入口 | 当前行为 | 验证/边界 |
|---|---|---|
| `/v1/chat/completions` | OpenAI 兼容透传，支持 SSE 用量采集 | 模拟上游覆盖正常/大响应、首尾 usage、缓存 token、流式回退；真实供应商未调用 |
| `/v1/messages` | Anthropic 兼容透传 | 既有测试覆盖 message_start/delta 用量合并；非流式支持顶层和 message.usage |
| `/v1/responses` | 按现有路由和桥接转换为 chat | 既有 responses 测试通过；不能据此承诺 OpenAI 全部工具和所有事件类型完全等价 |
| `/v1/embeddings` | OpenAI 兼容入口 | 既有测试通过，具体模型兼容性由上游决定 |
| `/v1/audio/transcriptions` | multipart 音频 → MiMo chat JSON → text/JSON 转写结果 | 已修正 JSON Content-Type；模拟严格上游通过；不是通用音频协议透传 |
| 音频生成/转写转换 | 保持现有响应转换流程 | 已修复转换后丢失 usage：JSON/text/音频三种输出均按上游原始用量记账；仍未验证真实音频质量或供应商音频专有计价规则 |

## 用量与金额

- 大正文不再依赖尾部 64 KiB 是完整 JSON；逐块观察 usage，正文原样透传。
- 单个 usage 对象和 SSE 行的采集上限为 64 KiB；异常超长部分跳过，不无限缓冲，SSE 在换行后恢复。上游未报告或格式非法的用量不会推测补账。
- 新请求日志保存计费币种，价格变更不改写快照；历史空币种记录只能回退当前价格表，无法恢复原始币种。
- 趋势 `cost_by_currency` 为权威字段；混合点 `cost=0`。按模型日志摘要现在按模型和币种分组，同一模型可能多行。
- 预算按 UTC 的日/月已完成用量判定，是软限制；单次请求和在途并发可能超额。启用/禁用/切换周期不丢失进程内累计用量，启动从独立账本回填。

音频桥接转换需要完整 JSON，上游响应超过32 MiB时返回502并关闭响应体；这个上限是输入体大小限制，不代表总内存占用上限。若转换失败前已提取到真实usage，仍记录该用量。

## 资源与运行

- 文件数据库保留一个数据面连接，增加一个只读统计连接；使用 WAL，无新增服务。今日汇总合并为一次扫描，延迟分位数以精确直方图聚合，减少重复延迟样本传输；内存与不同延迟值数量相关，最坏仍随样本增长。统计仍消耗 CPU、内存和磁盘，多个统计请求在只读连接上排队，不能视为完全隔离。
- 日志默认永久保留；根据部署磁盘容量设置 `LITEGATE_LOG_RETENTION_DAYS`。预算账本独立于请求日志清理。
- 上游空闲超时仍默认关闭，使用 `LITEGATE_STREAM_IDLE_TIMEOUT` 配置；本轮不改变现有部署行为。
- 备份恢复以 `VACUUM INTO` 的数据库文件为单位；使用外置主密钥时必须单独保管同一 `LITEGATE_SECRET`。
- 共享云机器短压测不能保证生产 SLA。命令、原始结果和限制见 `VALIDATION.md`。

最终审查补充：负数用量及单笔token加法溢出不计入账单；预算历史回填改为原子提交并读取币种快照。日志与预算日账本仍分开写入，异常退出/存储失败下不承诺跨层原子记账。完整剩余项见 [FINAL_REVIEW.md](FINAL_REVIEW.md)。
