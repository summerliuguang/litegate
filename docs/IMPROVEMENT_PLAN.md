## 执行原则

- 先运行新增回归并记录失败，再修复，最后完整验证。
- 历史日志没有币种快照，无法恢复过去被修改的价格币种；兼容回退必须明确，不伪造历史准确性。
- 预算在完成请求后按真实用量累计，可能被已放行的并发/单次大请求超出；硬预算预留属于后续独立设计。
- 对上游未提供或异常超大的 usage 不虚构用量；正文透传与用量采集分离，内存保持有界。
- 页面设计和全链路性能只根据实际运行结果评估。竞品作为需求参照，不引入其源码。
